# 옆집 손주 쇼츠 #1 — 약 봉투, AI한테 읽어 달라고 하세요

- 형식: 유튜브 쇼츠 (세로 1080×1920), 약 50초
- 진행: 옆집 손주 캐릭터 + AI 목소리 (1편과 같은 남성 목소리 M1)
- 업로드 제목(추천): **약 봉투 글씨 작아서 답답하셨죠? 사진만 찍으면 AI가 읽어 줘요**
- 원칙: 화면 속 약 봉투는 가상의 것 (실제 약 이름 없음). 개인정보 가리기와 "약사님께 한 번 더"를 꼭 넣음

---

### scene01 · 훅 (공감)
**화면:** 깨알 같은 글씨의 약 봉투가 화면 가득 → 돋보기를 대도 안 보임 → "😣"

> 약 봉투 글씨, 너무 작아서 답답하셨죠?
> 이제 사진만 찍어서 보여 주면, AI가 대신 읽어 드려요!

### scene02 · 사진 찍기
**화면:** 휴대폰 대화 앱 → 카메라 버튼 강조 → 약 봉투를 비추는 카메라 화면 → 찰칵 → 사진이 올라감

> 챗GPT나 제미나이 앱을 열고, 카메라 버튼을 누르세요.
> 약 봉투를 찍어서 올리면 돼요.

### scene03 · 말로 물어보기
**화면:** 마이크 버튼 강조 → "듣고 있어요" 화면 → 말한 내용이 글자로 나타남

> 그다음 마이크 버튼을 누르고, 이렇게 말해 보세요.
> "이 약 언제, 어떻게 먹어야 하고, 주의할 점이 뭔지 알기 쉽게 설명해 줘."

### scene04 · 대답
**화면:** 큰 글씨 대답 카드 3줄이 차례로: 🕗 언제 / 💊 얼마나 / ⚠️ 조심할 것

> 그럼 이렇게 쉽게 정리해 줘요.
> 언제 먹는지, 얼마나 먹는지, 조심할 것까지요.

### scene05 · 꼭 기억하세요
**화면:** 약 봉투의 이름 칸을 손가락(스티커)으로 가림 → "가리고 찍기" / 약사 아이콘 → "약사님께 한 번 더"

> 꼭 기억하세요!
> 약 봉투에 있는 이름은 가리고 찍으세요.
> 그리고 AI 설명은 참고만 하시고, 궁금한 건 약사 선생님께 한 번 더 물어보세요.

### scene06 · 마무리
**화면:** "건강검진 결과표도 OK 📋" → 구독 버튼

> 건강검진 결과표도 이렇게 물어볼 수 있어요.
> 도움 되셨으면 구독 눌러 주세요!

## 확인한 사실

- 챗GPT·제미나이 모두 사진을 올리고 말로 물어볼 수 있음 (무료는 사진 수 제한이 있을 수 있음) — 1편 SCRIPT.md 출처와 같음
- 의료 정보는 참고용이며 약사·의사 확인이 필요하다는 점을 영상 안에서 직접 말함
